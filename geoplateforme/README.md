# geoplateforme

Examples using [IGN Geoplateforme](https://geoservices.ign.fr/) services (requires network access).

* [wms-heights-normals](wms-heights-normals.ipynb) : Retrieve heights from the [WMS-R service](https://data.geopf.fr/wms-r/wms) and compute a normal map (images written to `output/`).
