# neural-networks

Basic neural networks with [pytorch](https://pytorch.org/) (uses GPU if available).

* [01-two-classes-linear](01-two-classes-linear.ipynb) : Binary classification of points with linearly separable classes.
* [02-two-classes-non-linear](02-two-classes-non-linear.ipynb) : Binary classification of points with non-linearly separable classes.
