# geometry

Computational geometry algorithms based on simple types defined in [geom_types.py](geom_types.py) (`Point`, `Segment`, `Circle`).

* [tangent-point-circle](tangent-point-circle.ipynb) : Tangents from a point to a circle.
* [tangent-circle-circle](tangent-circle-circle.ipynb) : Tangents between two circles.
* [intersection-circle-circle](intersection-circle-circle.ipynb) : Intersection of two circles.
* [intersection-segment-circle](intersection-segment-circle.ipynb) : Intersection of a segment and a circle.
